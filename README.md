# Flappy Bird Game 🐦

A simple Flappy Bird clone built using **HTML5 Canvas** and **JavaScript**.

## Features

* 🎮 Smooth bird movement with gravity
* 🏗️ Randomly generated pipes
* 💥 Collision detection
* 🔊 Hit & game-over sound effects
* 🏆 Live score counter
* 🔄 Restart after game over

## Tech Stack

* HTML5
* JavaScript
* Canvas API

## How to Run

1. Clone the repository.
2. Open `index.html` in your browser.
3. Press **Space** to start and fly.

## Controls

* **Space** → Jump
* **Space (after Game Over)** → Restart
